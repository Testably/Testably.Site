Benchmarks

These benchmarks compare the happy-path overhead of aweXpect.Reflection (passing assertions, the dominant case in a healthy test suite) against the equivalent FluentAssertions calls.

Methodology
  • Suite: HappyCaseBenchmarks driven by BenchmarkDotNet.
  • Job: MediumRun with the in-process toolchain.
  • Runner: ubuntu-latest GitHub Actions agent, refreshed on every push to main.
  • FluentAssertions has no expectations on nullability or dependencies. For these, its benchmark does what a FluentAssertions user writes instead, which does not cover everything aweXpect.Reflection verifies.
  • Each tab shows the latest measured time and allocated memory; bars are scaled within the row so length corresponds to magnitude. Lower is better.

Verifies the architecture rule that no type in a namespace of an assembly depends on the System.Net namespace. FluentAssertions collects the types of the fields, properties, method return values and method parameters and verifies that none of them is in the namespace. This is not equivalent: it ignores e.g. base types, interfaces, generic arguments and attributes.

Time

FluentAssertions240.11 µs+11167%
Memory
aweXpect3.19 KiB

Captured on commit 91e67fd2 (2026-10-28) on ubuntu-latest.
aweXpect
await Expect.That(In.AssemblyContaining<HappyCaseBenchmarks>().Types().WhichAreWithinNamespace(_namespace))
    .DoNotDependOn("System.Net");
FluentAssertions
AllTypes.From(_assembly).ThatAreUnderNamespace(_namespace).SelectMany(GetSignatureTypes).Should()
    .NotContain(type => type.Namespace != null &&
                        (type.Namespace == "System.Net" || type.Namespace.StartsWith("System.Net.")));
