Benchmarks

These benchmarks compare the happy-path overhead of aweXpect.Json (passing assertions, the dominant case in a healthy test suite) against the equivalent FluentAssertions calls.

Methodology
  • Suite: HappyCaseBenchmarks driven by BenchmarkDotNet.
  • Job: MediumRun with the in-process toolchain.
  • Runner: ubuntu-latest GitHub Actions agent, refreshed on every push to main.
  • FluentAssertions has expectations on JsonNode, but not on JSON strings or JsonElement. Where it lacks an expectation, its benchmark does what a FluentAssertions user writes instead, e.g. parse the string into a JsonNode.
  • Each tab shows the latest measured time and allocated memory; bars are scaled within the row so length corresponds to magnitude. Lower is better.
